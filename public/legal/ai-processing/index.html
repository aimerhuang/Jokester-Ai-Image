1. 适用范围与自主选择

本告知仅适用于需要第三方 AI 处理的图片生成、图片编辑和相关功能。只有当你主动提交任务时，才会触发本告知所述处理。

这是独立授权。你注册时接受《隐私政策》和《服务条款》，不等于已经同意第三方 AI 处理。首次使用前，你需要单独确认本告知。

你可以拒绝授权。拒绝不会影响登录、账户管理、积分查询、已上传图片管理等不依赖第三方 AI 的功能，但无法创建相应的 AI 生成任务。

2. 可能的接收方

服务端会根据你选择的模型和当前启用路由确定实际处理链路，可能涉及：

接收方类别当前用途
OpenAI 或提供 OpenAI Images 兼容能力的处理主体完成 GPT Image 系列图片生成或编辑
Google 或提供 Gemini Images 兼容能力的处理主体完成 Gemini、Nano Banana 系列图片生成或编辑
DawCode（api.dawclaudecode.com）等服务端配置的 AI API 路由服务鉴权、路由并转发请求至相应上游模型处理链路

授权记录使用 openai、google 标识模型处理类型。路由或接收方发生对你权益有重大影响的变化时，我们会更新本告知并在需要时重新取得同意。

3. 处理的信息

根据你实际使用的功能，可能发送以下必要信息：

  • 你主动输入的提示词；
  • 模型、尺寸、画幅比例、质量等生成参数；
  • 你在当前任务中主动选择的参考图片或蒙版；
  • 完成请求、返回结果和实施安全防滥用处理所必需的技术信息。

反向提示词目前用于本服务内部的任务记录、幂等和内容安全校验，不会因为保存于任务记录就当然发送给第三方。已上传但未在当前任务中选择的图片也不会仅因上传而自动发送。

4. 处理目的、方式与地点

上述信息仅用于按你的指令完成图片生成或编辑、返回生成结果，以及进行必要的鉴权、路由、安全防滥用、故障排查和履约核验。我们不会将其出售或用于广告营销。

数据通过加密的 HTTPS/API 连接发送。第三方 AI 服务和 API 路由服务可能在中华人民共和国境外处理数据，具体地点取决于当前路由、上游基础设施及其服务安排。

5. 保存期限与模型训练

本服务会按照《隐私政策》保存你的任务记录、提示词、私有图片和生成结果，直至你删除相关资源、账号注销完成或提供功能不再需要；法律另有要求的除外。

第三方 AI 服务和 API 路由服务可能按照其 API 服务条款，为完成请求、安全防滥用、故障排查或争议处理保留必要记录。不同路由的具体期限可能不同，我们会优先采用最小必要留存设置。

我们不会使用你的内容训练自有通用模型，也不会主动要求或授权第三方将你的内容用于广告或与本次任务无关的通用模型训练。若某一处理链路的训练或留存政策发生重大变化，我们会在继续使用前更新告知并依法重新取得授权。

6. 拒绝、撤回与删除

你可以拒绝本授权，也可以通过联系邮箱要求撤回。撤回只影响此后创建的新任务，不影响撤回前已经合法完成的处理；撤回后，服务端会拒绝需要相应 Provider 的新任务。

你可以分别删除任务记录、自己拥有的私有图片和 Asset，或申请注销账户。第三方已经完成的处理和依法需要保留的安全、交易或争议记录，可能无法即时同步删除。

7. 敏感信息与未成年人

请勿在提示词或图片中提交身份证件、银行卡、账号密码、医疗健康、生物识别、精确位置、未成年人敏感信息或其他与图片生成无关的个人敏感信息。

不满 14 周岁的未成年人不得注册或使用本服务。已满 14 周岁但未满 18 周岁的用户应在监护人阅读并同意相关法律文档后使用，并避免提交本人或他人的敏感信息和私密图片。

接收方、处理目的、信息种类、跨境安排、保存期限或模型训练政策发生重大变化时，我们会发布新版本，并在继续处理前依法重新取得同意。
